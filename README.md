# Beyond Point Estimates: Bayesian GP Inference for In-Game NBA Win Probability

Every deployed NBA win probability model — ESPN, NBA.com, the betting markets — gives you a
single number. When the broadcast says the home team has a 73% chance, it tells you nothing
about whether that 73% comes from a game state seen thousands of times or from a corner of the
state space the model has barely visited.

This project replaces the point estimate with a full posterior. A Gaussian Process is fitted to
score margin and time remaining, so every game state returns a win probability **and** a
credible interval, plus a decomposition of that uncertainty into epistemic (what the model
doesn't know) and aleatoric (what nobody can know) components.

## Results

Held-out test set is the entire 2023–24 regular season. Training is 2018–19 through 2022–23,
with zero game overlap between splits.

| Model | Log-Loss | Brier | Accuracy |
|-------|----------|-------|----------|
| LR (simple) | 0.4998 | 0.1674 | 74.81% |
| LR (poly deg 3) | 0.4804 | 0.1627 | 74.94% |
| XGBoost | **0.4766** | **0.1618** | **74.97%** |
| GP (RBF + Matérn 1.5) | 0.4831 | 0.1636 | 74.79% |

The GP lands 0.007 log-loss behind XGBoost. That gap is real but small, and it buys a calibrated
credible interval at every point in the game — something none of the baselines can produce.

**Data:** 6,962 games, 174,050 game-state observations, 6 seasons of play-by-play.
**GP training set:** 634 binned grid points, mean 226 observations per bin.
**Kernel selection:** RBF + Matérn 1.5 wins on log marginal likelihood (589.68).
**Coverage:** 95% credible intervals achieve 80% empirical coverage.

## The uncertainty decomposition

This is the part a point estimate cannot give you.

| Context | Epistemic | Aleatoric | n |
|---------|-----------|-----------|---|
| Blowout (\|margin\| ≥ 15) | 0.0480 | 0.0527 | 6,231 |
| Clutch (\|margin\| ≤ 5, < 5 min) | 0.0393 | 0.3142 | 988 |
| Normal | 0.0385 | 0.3145 | 23,531 |

Blowouts and decided games differ from live games by roughly **6x on the aleatoric dimension**.
A blowout is uncertain because the model has seen few of them; a clutch possession is uncertain
because the game genuinely is. Those are different problems, and only the first one gets better
with more data.

## What the kernel learned

Bayesian model selection over five candidate priors picked a composite kernel:

```
k = 0.988² · RBF(ℓ = [0.72, 4.99]) + 0.262² · Matérn₁.₅(ℓ = [1.13, 2.94]) + White(σ² = 0.01)
```

Normalized, that is **93% smooth and 7% rough**. Win probability drifts gradually most of the
time and occasionally jumps — an 8-0 run, a dagger three, an and-one. No basketball knowledge
was encoded in the kernel design; marginal likelihood optimization found this structure on its own.

| Kernel | Log Marginal Likelihood |
|--------|------------------------|
| **RBF + Matérn 1.5** | **589.68** |
| Matérn 1.5 | 587.23 |
| Matérn 2.5 | 587.15 |
| RBF | 577.90 |
| Rational Quadratic | 557.74 |

## Reproducing

```bash
git clone https://github.com/lsjao/nba-gp-win-probability.git
cd nba-gp-win-probability
pip install -r requirements.txt
```

Run `notebooks/01_data_collection.ipynb` first to pull the play-by-play data into `data/raw/`.
The full six-season pull takes a while and is rate-limited by the NBA API. Then run
`notebooks/nba_gp_complete.ipynb` end to end — it writes the processed datasets, the trained
model, and every figure in `figures/`.

Neither the raw data nor the trained artifacts are tracked in git: the play-by-play files run to
several hundred megabytes.

## Method in one paragraph

Play-by-play is sampled at 2-minute intervals through regulation, giving 24 snapshots per game
labelled with the eventual home-team outcome. For GP training those observations are binned on a
grid (2-point margin bins, 120-second time bins, minimum 5 observations per bin) and the empirical
win rate in each bin becomes the regression target. This is GP regression on binned rates rather
than full GP classification — a deliberate tradeoff that reduces 143,300 observations to 634 grid
points and keeps exact O(n³) inference feasible. A bounded WhiteKernel plus diagonal regularization
prevents the posterior from collapsing to overconfidence, and all intervals are clipped to [0, 1].

Known limitations are stated plainly in the paper: two features only (no team quality, injuries, or
possession), the binning approximation, credible interval coverage that plateaus at 80% because the
posterior models function uncertainty rather than binary outcome variance, and no benchmark against
proprietary models since none of them archive their predictions.
